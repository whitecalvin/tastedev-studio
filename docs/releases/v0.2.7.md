# TASTESTUDIO 0.2.7

## 이번 판에서 달라진 것

- 만료되거나 취소된 ChatGPT 연결을 인증 오류로 구분하고, 기존 인증 파일을 삭제하지 않아도 다시 로그인할 수 있도록 개선했습니다.
- 프로젝트에 리더·설계·구현·독립 검토·문서화 팀을 구성하고, 작업 의도·역할 배정·품질 근거·인계 수신함·승인된 규칙을 오케스트레이션 화면에서 관리할 수 있습니다.
- 데스크톱에서 공지사항을 불러오거나 공지 링크를 여는 동작이 권한 오류로 차단되던 문제를 수정했습니다.
- Windows 업데이트를 준비한 뒤 ‘지금 재시작 / 나중에’를 선택합니다. 나중에는 앱과 작업을 유지하며, 재시작 시 같은 제품의 각 인스턴스에서 작업 완료를 확인받은 뒤 종료·설치·재실행합니다.
- Windows 업데이트 후 앱 창의 생성·응답을 확인하고 활성화를 요청합니다. 창 없이 실행되거나 표시 요청에 실패한 경우 재시작 완료로 처리하지 않습니다.
