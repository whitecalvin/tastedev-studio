# TASTESTUDIO 0.2.9

## 이번 판에서 달라진 것

- 출력이 많은 작업에서도 Core와 Agent의 연결을 유지하도록 출력 전송 확인과 대기 상한을 추가했습니다.
- vendor 소스가 포함된 프로젝트 Snapshot에서도 AI 수정 승인과 재시험 이력을 저장할 수 있도록 수정했습니다.
- 완료된 AI 작업을 다시 실행하지 않고, 봉인된 수정안과 기존 검증 계획으로 재시험할 수 있습니다. 재시작 후 승인 만료와 재시험 이력을 보존합니다.
- 게임 프레임워크의 최소 6단계 흐름 지원 상태를 반영하고, 프로젝트 문서를 보존하면서 누락된 엔진 참조 문서를 검토용 Snapshot에 보충합니다.
- 게임 프레임워크 온보딩의 설정·단계 보조 명령에 원본 무결성과 승인 파일 범위 검사를 추가했습니다.
- 격리 작업 공간에서 독립 작업 계약을 선택할 수 있도록 수정하고, 통합 검토 제출 버튼과 부모 기준 커밋을 보존하는 Snapshot 식별 정보를 보강했습니다.
- 되돌리기가 미저장 편집이나 파일 충돌로 거부될 때, 기존 작업이 잘못된 복구 상태로 바뀌지 않도록 수정했습니다.
- 격리가 필요한 AI 로컬 검증을 차단하고, 승인된 원격 재시험의 산출물 전송과 큐 제출 실패 복구를 개선했습니다.
- 데스크톱 앱의 프로젝트 생성·Git 협업·언어 도구·디버깅 명령에 누락된 실행 권한 등록을 수정했습니다.
- 선택 노드에서 실제 Agent 상태·실행·Source·대기 이유를 확인하고 실행 이력과 스케줄 설정으로 이동할 수 있습니다. 그래프 스케줄의 시작 노드도 명확히 표시합니다.
- 실행 검토에서 단계별 격리 권한과 최초 프로세스를 포함한 프로세스 상한을 확인할 수 있습니다.
- 빌드 산출물의 민감값 검사를 강화하고, 검사 중에도 취소 요청과 시간 제한을 확인합니다.
- 격리가 필요한 작업을 지원하지 않는 Agent에 배정하지 않으며, 실행 프로필의 격리 요구를 제거하는 변경을 차단합니다.
- 프로젝트 생성에서 기술과 엔진을 따로 선택하고 생성 파일을 미리 볼 수 있습니다. 오케스트레이션에서 준비 상태를 확인하고 첫 테스트의 노드 초안을 검토해 구성할 수 있습니다.
- 원본 Claude 스킬을 격리 공간에서 실행하고, 변경을 검토·승인한 뒤 Godot 수정 결과를 Agent 테스트로 확인할 수 있습니다. 중단된 원본 세션 재개와 프레임워크 모드 설정을 지원합니다.
- Claude-Code-Game-Studios의 고정 역할·스킬 카탈로그와 게임 엔진별 템플릿 연결을 추가했습니다. 선택한 팀을 노드로 배치하고 원문 프롬프트와 설정 출처를 확인할 수 있습니다.
- 오래 걸린 빌드의 산출물도 승인된 작업·실행 기한 안에서 전달할 수 있습니다.
- 후속 작업·장비 준비 상태·산출물 전달·복구 지점을 함께 확인하고, 놓친 실행과 제한된 재시도 정책 및 TASTEFILES 전달 초안을 설정할 수 있습니다.
- 겹치는 통합 요청의 순서를 관리하고 장비별 실행 정책을 설정할 수 있습니다. 선행 작업 성공 스케줄, 실행 단계·이력 확인, 대기 작업 재배정을 추가했습니다.
- 통합 검토함에서 변경을 검토하고 파일 생성·삭제·이름 변경을 승인해 적용할 수 있습니다. 충돌 해결과 후속 작업의 소스 재검토를 지원합니다.
- 기존 Windows·Linux 배포를 유지하면서 macOS 패키지만 추가하는 출시 명령을 추가했습니다.
- macOS Apple Silicon용 DMG 설치 패키지와 Homebrew 배포 경로를 추가했습니다.
- 첫 실행 시 창을 해당 모니터의 가운데에 배치합니다.
- Windows 업데이트 후 앱 준비가 확인되면 상태 창을 바로 닫도록 고정 대기를 제거했습니다. 여러 창의 미저장 작업 보호는 유지됩니다.

## What's new [en]

- Added acknowledged, bounded output delivery to keep Core and Agent connected during output-heavy tasks.
- Fixed saving AI fix approvals and retest history for project snapshots containing vendored source.
- Retry validation of sealed AI changes with the original test plan without replaying a completed AI task. Approval expiration and retry history are preserved after restart.
- Updated support for the six-step minimal game workflow and added missing engine references to reviewed snapshots while preserving project documents.
- Added original-file integrity and approved-file scope checks to game-framework onboarding configuration and stage helpers.
- Fixed standalone work-contract selection in isolated workspaces, the integration-review submission button, and preservation of the parent baseline in snapshot identity.
- When unsaved edits or file conflicts block a revert, the existing attempt now keeps its state and completed recovery record.
- Required isolation is preserved during AI validation. Approved remote retests can transfer declared outputs and recover safely from queue submission failures.
- Fixed missing native command permissions for project creation, Git collaboration, language tools and debugging in the desktop app.
- Inspect Agent state, Runs, Source and waiting reasons from the selected node, with links to Run history and schedule settings. Graph schedules show their entry node.
- Execution review now shows each step’s isolation permissions and process limit, including the root process.
- Build artifact checks for sensitive data are stricter and now respect cancellation requests and time limits during scanning.
- Tasks requiring isolation are not assigned to unsupported Agents, and execution profiles cannot silently lose their isolation requirements.
- Choose technology and engine separately, preview project files, inspect preparation checks, and review a first-test node draft in Orchestration.
- Run original Claude skills in isolation, review and approve changes, and verify Godot fixes with Agent tests. Resume interrupted native sessions and adjust framework modes.
- Added a pinned Claude-Code-Game-Studios role and skill catalog with game engine template bindings. Place selected teams on the canvas and inspect complete original prompts and configuration sources.
- Outputs from longer builds remain transferable within the approved step and execution deadlines.
- Inspect dependent work, device readiness, artifact delivery and recovery steps, with bounded missed-run/retry policies and TASTEFILES delivery drafts.
- Manage overlapping integrations and device execution policies, trigger schedules after successful dependencies, inspect steps and history, and review queued reassignment.
- Review changes in the integration inbox and approve file creation, deletion and renames, with conflict resolution and Source re-review for dependent work.
- Added a release command to add macOS packages while preserving existing Windows and Linux releases.
- Added DMG packaging and Homebrew distribution for macOS Apple Silicon.
- On first launch, the window is centered on its monitor.
- Removed fixed waits after Windows updates: the status window closes as soon as the app is ready. Protection for unsaved work across multiple windows is preserved.
- Submit tested task changes to the original work and complete it after integration retests, independent review and acceptance.
