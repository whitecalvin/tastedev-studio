## 이번 판에서 달라진 것

- Windows 업데이트를 준비한 뒤 ‘지금 재시작 / 나중에’를 선택합니다. 나중에는 앱과 작업을 유지하며, 재시작 시 같은 제품의 각 인스턴스에서 작업 완료를 확인받은 뒤 종료·설치·재실행합니다.

- Windows 업데이트 후 앱 창의 생성·응답을 확인하고 활성화를 요청합니다. 창 없이 실행되거나 표시 요청에 실패한 경우 재시작 완료로 처리하지 않습니다.

## What's new [en]

- Windows: Update ready → Restart now / Later. Save or finish any work in this instance before continuing. Later keeps your app and work open. No process will be forcibly terminated.

- After a Windows update, restart checks now require a responsive app window and request its activation. A process without a window or with a rejected activation is no longer reported as a completed restart.

## What's new [ja]

- Windows: 更新の準備ができました → 今すぐ再起動 / 後で. このウィンドウの作業を保存または完了してから終了を承認してください。「後で」はアプリと作業を維持します。強制終了しません。

- Windows 更新後はアプリのウィンドウと応答を確認して表示を要求します。ウィンドウがない場合や表示要求が失敗した場合は再起動完了としません。
