## 이번 판에서 달라진 것

- Windows 업데이트의 창 종료 대기·설치·재시작 상태를 별도 진행 창에서 표시합니다. 종료 중인 앱의 경로 조회 오류를 처리하고 미저장 작업을 강제로 닫지 않습니다.

## What's new [en]

- Windows updates now show window-close waiting, installation and restart status in a separate progress window. Exiting-process path lookup races are handled without forcibly closing unsaved work.
