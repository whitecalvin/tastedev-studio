# TASTESTUDIO 0.2.8

## 이번 판에서 달라진 것

- 작업별 Git 격리 공간과 변경 비교, 승인 후 원본 통합, 통합 소스 재테스트와 작업 공간 보관·복원을 추가했습니다.
- 팀 작업의 실행 전 점검, 승인된 실행 인계, 작업별 Source·재테스트 근거, AI 운영 한도와 완료 보고서를 추가했습니다. 여러 작업 초안을 한 번에 검토·승인해 대기열에 등록할 수 있습니다.

## What's new [en]

- Added isolated Git task workspaces, change comparison, approved integration into the original source, integration retests, and workspace archive/restore.
- Added team execution preflight, approved handoffs, task Source and retest evidence, AI operating limits, and completion reports. Multiple work drafts can be reviewed and approved together for the queue.
